
Social Engineering Detector

1. Project Overview

The Social Engineering Detector is a Python-based
cybersecurity awareness project designed to identify
possible social engineering and phishing indicators
in suspicious messages.

Social engineering is a cyberattack technique where
criminals manipulate people into revealing sensitive
information or performing actions that compromise
their security.

 2. Project Objectives

- Raise awareness about social engineering attacks.
- Identify suspicious messages.
- Detect common phishing indicators.
- Educate users about online safety.
- Encourage responsible cybersecurity practices.

 3. Technologies Used

- Python 3
- Regular Expressions
- Git
- GitHub

 4. Main Features

- Detects urgency and threatening language.
- Identifies suspicious password requests.
- Detects financial manipulation phrases.
- Identifies possible prize scams.
- Flags suspicious links.
- Classifies messages by risk level.
- Provides cybersecurity recommendations.

 5. Risk Classification

HIGH RISK:
Several suspicious indicators have been detected.

MEDIUM RISK:
Some suspicious indicators have been detected.

LOW RISK:
Few or no listed indicators were detected.

 6. How to Run the Program

1. Install Python 3.
2. Download or clone the repository.
3. Open a terminal in the project folder.
4. Run:

   python social_engineering_detector.py

5. Enter a sample message.
6. Review the analysis results.

7. Cybersecurity Importance

Social engineering attacks exploit human trust,
fear, urgency and curiosity.

Users should:
- Verify unexpected requests.
- Never share passwords or OTP codes.
- Avoid suspicious links.
- Use multi-factor authentication.
- Report suspected phishing messages.

 8. Limitations

This project uses predefined keywords and phrases.
It does not use artificial intelligence or advanced
machine learning.

It may produce false positives or fail to identify
new social engineering techniques.

A LOW RISK result does not guarantee safety.
